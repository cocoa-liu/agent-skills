# 指标计算与随机性分析

仅在计算差异、处理随机性或解释统计结果时读取。正确性依据、修复闭环及交付/暂停标准均在 [SKILL.md](../SKILL.md)，不需先读本文件才能执行。

## 1. 指标与差异计算

令 B 为基线值、C 为候选值，统一把正数表示为变差：

- 越低越好（WER、损失、延迟）：D = C − B。
- 越高越好（准确率、相似度、吞吐）：D = B − C。
- 绝对容差为 ε 时，比较 D ≤ ε；同时存在绝对质量门槛与异常限额时也必须满足。
- 若采用相对退化：D_rel = D / |B| × 100%；B=0 时相对值无定义，改用事先约定的绝对尺度。明确“百分点”和“相对百分比”，不可互换。

例如 WER=(替换S+删除D+插入I)/参考词数。139/11943→153/11943，是净增14词错误、增加0.1172个百分点，相对增加约10.07%；不是14条请求失败。若事先接受的容差为0.10个百分点，则该次观测超线，进入排查；此处0.10只是演算例子，不是默认标准。

WER 同时报告 S/D/I、参考词数、有错样本数和约定的严重异常数。多次运行分别列值，不挑最好一轮；不可将相关的重复输出当成新增独立样本夸大统计把握。

## 2. 随机性影响判定时

只在差异可能受采样/调度影响且会改变验收结论时增加复测：固定数据、权重、参数及实际随机源，尽量成对比较基线与候选；记录请求标识是否参与种子生成。固定 seed 不保证异步调度或所有生成阶段确定。

复测前说明本轮要区分什么，以及汇总和停止规则；可先做少量成对完整复测，报告所有轮次，仍不清楚就补有区分力的证据或保持待验证。项目有置信区间/非劣性标准时直接复用；不要机械要求每个任务跑固定三轮，也不能“再跑到某一轮通过为止”。单次低 WER 或两次有波动，都不足以证明随机性解释了全部差异。
